# Support

Use [GitHub issues](https://github.com/spkon/ha_google_wifi/issues) for reproducible
bugs and feature requests. Report security issues using [SECURITY.md](SECURITY.md).
This is a community project; support is voluntary.

Before reporting a problem:

1. Read [installation/troubleshooting](INSTALL.md) and
   [authentication help](docs/AUTHENTICATION.md).
2. Record the integration version, HA Core version, installation method, Google
   WiFi/Nest model and whether the entry uses local or Google account access.
3. Explain the expected and observed behavior. For a saved speed test, include
   its age using a fictional point name; a saved test is not current traffic.
4. Download this version's HA diagnostics and review the contents before sharing.
   Do not attach raw Google telemetry, browser storage, config entries or backups.
5. Include a small reproduction with fictional identifiers and the action status
   displayed by HA. Do not repeatedly restart a point to collect evidence.

The [compatibility and readiness matrix](docs/RELEASE_READINESS.md) distinguishes
automated framework checks from live hardware validation. A model not yet tested
is not automatically supported because it appears in Google Home.

English is used for documentation, issues and code comments. The integration and
panel have English and Portuguese UI translations; contributions are welcome.
Donations through [Buy Me a Coffee](https://buymeacoffee.com/spkon) are optional and
do not grant different features or support priority.
